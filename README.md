# 学生时代牌 · 金榜题名

一个校园题材的**卡牌 Roguelike 网页游戏**。纯前端：不需要后端、不需要编译、不需要装依赖，打开 HTML 就能玩。

- 当前版本：**v0.17.4**
- 技术栈：原生 HTML + CSS + JavaScript（无框架、无构建工具）
- 素材：PNG 立绘/插画 + WAV/M4V 音频视频

---

## 一、快速开始

### 方式 A：一键启动（Windows）

双击游戏目录下的 **`启动游戏.vbs`**。

它用 Edge 的应用模式打开一个无地址栏窗口，并使用独立浏览器配置，不会污染你日常的浏览器数据。

### 方式 B：本地服务器（推荐，跨平台）

```bash
# 在仓库根目录执行
python -m http.server 8080 --directory 金榜题名v0.17.4
```

然后浏览器访问：

```
http://localhost:8080/学生时代牌-网页版.html
```

> 也可以直接双击 `学生时代牌-网页版.html`（`file://` 方式）。本地服务器方式在缓存、音视频加载上行为更接近真实浏览器，调试时更省心。

## 三、⚠️ 改内容前必读：这个项目有两层覆盖机制

**选错层会白干一场**，请务必对号入座。

| 你的目的 | 正确做法 | 生效范围 |
|---|---|---|
| 试试某个数值 / 文案好不好 | 打开**游戏编辑器**改，改动自动存在浏览器 `localStorage` | 只影响你自己这台电脑，换电脑或清缓存就没了 |
| 正式改动，要让大家都能看到 | 直接改 `js/` 下的数据文件，**或**把改动写进 `js/editor-overrides.js` | 提交后所有人生效 |

### 关于 `js/editor-overrides.js`

它是**代码级覆盖层**。游戏启动时，`editor-store.js` 会把它的内容合并进 `G.CARDS`、`G.EVENTS`、`G.MONSTERS` 等数据表，从而覆盖原始数据。

- 编辑器的「**写入游戏**」按钮生成的就是这个文件
- 编辑器界面里的「**导出全部**」生成的 `金榜题名-编辑器数据.json` 是**个人备份**，已在 `.gitignore` 中排除，**不要提交**

> 想把编辑器里的成果贡献给全组：把它导出后，将内容整理进 `js/editor-overrides.js` 再提交。

团队协作流程、提交规范与素材规范见 **[CONTRIBUTING.md](CONTRIBUTING.md)**。
托管平台怎么选、怎么把仓库推上去，见 **[docs/托管平台选择与上传.md](docs/托管平台选择与上传.md)**。

简版流程：

```bash
git switch -c content/新增运动会事件     # 开一个分支
# ...改文件...
node tools/check-assets.mjs              # 提交前自检（必跑）
git add -A && git commit -m "content: 新增运动会系列事件"
git push -u origin content/新增运动会事件
# 然后在托管平台网页上发起 Pull Request
```

## 五、发布给玩家

玩家端走的是"更新包"模式：

1. 更新 `版本.json` 与 `version.js`（版本号、日期、更新说明）
2. 打包出 `金榜题名vX.X.X.zip`（内含 `更新清单.json` + `更新文件/`，带 MD5 校验）
3. 玩家把 zip 解压进游戏目录，双击 `一键更新.cmd` 完成更新

> 注：打包脚本 `构建更新包.ps1` **目前不在本仓库中**。如果你手上有，建议一并提交进 `tools/`，否则发布环节无法在新环境复现。

`*.zip` 已在 `.gitignore` 中排除——发布包体积大且可重新生成，不进版本库。

## 六、素材与体积说明

完整素材约 **135 MB**。为避免仓库膨胀：

- 视频 / 音频（`*.m4v` `*.mp4` `*.wav`）走 **Git LFS**
- 图片（PNG/JPG）按普通文件存储

**协作者首次克隆后需要执行一次：**

```bash
git lfs install
git lfs pull
```

否则视频和音频会是指向 LFS 的指针文件，游戏里会没有声音。
